# Hermes

Hermes Agent is an open-source, self-improving AI agent framework developed by
Nous Research. Unlike standard chatbots, it is designed to be a persistent
assistant that runs 24/7 on self-hosted infrastructure, such as a local
machine, a Raspberry Pi, or a Virtual Private Server (VPS).

On this platform, Hermes is deployed to instances by enabling it in the
cluster config; the daemon then manages it on the member machines.
