# OpenClaw

OpenClaw is a free, open-source, self-hosted personal AI assistant and
autonomous agent designed to run locally on a user's own devices, such as a
Mac, server, or VPS. Unlike traditional chatbots accessed via a web browser,
OpenClaw is software that the user installs and owns.

On this platform, OpenClaw is deployed to instances by enabling it in the
cluster config; the daemon manages its configuration (the server ships an
OpenClaw config baseline), and its local gateway exposes the available models.
